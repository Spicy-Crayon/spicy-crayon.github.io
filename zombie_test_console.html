🧟 Zombie Run — testconsole

Dit bestand wijzigt index.html niet. Het laadt je echte app hiernaast in een kader en bestuurt hem via dezelfde functies die de app zelf gebruikt — inclusief een nagemaakte GPS-beweging, zodat je een volledige Zombie Run (met je eigen audiobestanden) kan beluisteren zonder buiten te moeten lopen.

0. Waar zet ik dit bestand?

Simpelste manier: zet zombie_test_console.html gewoon in dezelfde GitHub-map als je index.html en je map audio/ZombieRun/… (met jouw eigen mp3/wav-bestanden erin), commit + push zoals je met elke andere wijziging doet. Open 'm dan gewoon via je bestaande live adres, bv. https://spicy-crayon.github.io/zombie_test_console.html — precies zoals je nu ook index.html zelf opent. Geen lokale server nodig, want GitHub Pages ís al een echte server.

Alternatief (zonder te publiceren): zet dit bestand op je eigen computer in dezelfde map als een kopie van index.html + de map audio/ZombieRun/…, en open die map via een lokale server, bv. python3 -m http.server 8000 in die map, dan naar http://localhost:8000/zombie_test_console.html. Rechtstreeks vanaf schijf openen (dubbelklikken, file://… in de adresbalk) werkt niet — dan kan de app geen audiobestanden ophalen en krijg je hiernaast een lege/404-pagina te zien.

1. Configuratie (test-instellingen)

Standaard hieronder staan korte tijden zodat je snel door alle fases heen komt. Zet ze hoger als je de échte timing wil testen.

1b. Geluid (optioneel — leeg = app-standaard)

Zelfde parameters als het Geluid-tabblad in de app zelf. Een veld leeg laten gebruikt gewoon de standaardwaarde uit ZOMBIE_AUDIO_DEFAULTS — je hoeft hier dus niks in te vullen tenzij je specifiek iets wil testen (bv. een heel korte radio-ruis-afkap, of vaker/harder achtergrondfx).
